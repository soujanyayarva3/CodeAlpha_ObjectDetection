# 🎯 AI Object Detection System

## 📌 Overview

This project is an AI-powered real-time Object Detection system developed as part of the CodeAlpha Artificial Intelligence Internship.

It uses the YOLO (You Only Look Once) deep learning model to detect and classify multiple objects in real-time through a webcam feed. The system identifies objects with bounding boxes and labels, making it suitable for real-world AI applications.

## 🚀 Features

* Real-time object detection using webcam
* Detects multiple objects simultaneously
* Bounding box visualization with labels
* Pre-trained YOLOv8 model
* Lightweight and fast performance
* Easy to run and extend

## 🧠 Technologies Used

* Python
* OpenCV
* Ultralytics YOLOv8
* Deep Learning

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/soujanyayarva3/CodeAlpha_ObjectDetection.git
```

Navigate to project folder:

```bash
cd CodeAlpha_ObjectDetection
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Or install manually:

```bash
python -m pip install ultralytics opencv-python
```

## ▶️ How to Run

Run the object detection system using webcam:

```bash
python object_detection.py
```

Press **Q** to exit the application.

* Live webcam feed
